Severity Rules

HIGH
- Completion rate is below 50%.
- More than 50% of submissions are Cancelled.
- More than 50% of submissions remain New.
- Multiple HIGH conditions occur together.

MEDIUM
- One unit contributes more than 40% of total submissions.
- One resident contributes more than 40% of total submissions.
- More than 40% of appointments are On Schedule.
- One appointment date contributes more than 30% of total submissions.
- One appointment time contributes more than 30% of total submissions.

LOW
- Minor operational observations.
- Data quality observations.
- General monitoring opportunities.

Rules

- Base every observation strictly on the provided analytics.
- If any severity rule is satisfied, you MUST return an anomaly.

- Describe only the observed operational pattern.

- Do NOT report the same issue more than once. Merge related observations into a single anomaly.
- Use concise, factual, and management-focused language.
- If historical comparison is unavailable, return an empty string ("") for the comparison field.
- Do not invent missing information.
- Return ONLY valid JSON.
- Do NOT wrap the response in markdown or code fences.
